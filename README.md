A modern, fully responsive e-commerce single-page application (SPA) built specifically for sports merchandise. This project demonstrates component-based architecture, dynamic routing, and reactive state management using the Vue.js ecosystem.

🔗 **[Live Demo: Click here to view the project](https://sports-shop-eta.vercel.app/)** ## ✨ Key Features
* **Dynamic Product Catalog:** Users can browse through various sports categories with real-time reactive filtering.
* **Shopping Cart State Management:** Implemented robust cart logic (add, remove, update quantities, calculate totals) using Vue's reactivity.
* **Responsive UI/UX:** Mobile-first design approach using Tailwind CSS, ensuring a seamless experience across all screen sizes.
* **Component Architecture:** Clean separation of concerns with reusable Vue components for products, cart layout, and navigation.

## 🛠️ Tech Stack
* **Frontend Framework:** Vue.js
* **Styling:** Tailwind CSS
* **Core Language:** JavaScript (ES6+), HTML5
